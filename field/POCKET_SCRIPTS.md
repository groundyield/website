# Pocket scripts — WhatsApp / SMS (offline copy)

Short versions of [ADVICE_SCRIPTS.md](../ADVICE_SCRIPTS.md) for phone notes.  
**Not for first community meeting.** Use after enrollment + consent.

---

## Opt-in

```
Olá — GroundYield (piloto Vilanculos).
Lembretes da época + respostas sobre a sua unidade.
SIM = continuar · PARE = sair
Dados públicos: ID da unidade, não nome completo (salvo consentimento).
team@groundyield.org
```

## Opt-out confirm

```
GroundYield: recebemos PARE. Não enviaremos mais mensagens.
Se foi engano, responda SIM.
```

## Pre-plant

```
GroundYield · Unidade {ID}
Semana: preparar terreno; confirmar semente + fertilizante (microdose).
Foto do talhão se quiser feedback. Semente melhorada? (sim/não)
```

## Planting

```
GroundYield · Unidade {ID}
Registe data de sementeira (AAAA-MM-DD) e cultura.
Não exceder doses do pacote. ESPAÇO = ajuda de espaçamento.
```

## Mid-season

```
GroundYield · Unidade {ID}
Ervas, pragas, água. Folha danificada? 1 foto à luz do dia.
Não aplique produto novo sem confirmar o nome.
```

## Pre-harvest

```
GroundYield · Unidade {ID}
Planear secagem + sacos herméticos. Reduzir perdas.
Após colheita: kg aproximados + data (mesmo estimativa).
```

## Supplier quote request

```
Bom dia — GroundYield (piloto aberto, dados públicos).
Pedimos orçamento escrito para: {item + spec}.
Incluir: preço, moeda, IVA, prazo de entrega em Vilanculos, garantia.
team@groundyield.org
```

## Safety (operator only)

- No rates above the published package without a written reason  
- Prefer photo over pest guess  
- Escalate uncertainty to a human partner
