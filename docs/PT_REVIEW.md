## Language quality notes (PT for Mozambique)

| Item | Note |
|------|------|
| Variety | European-leaning PT (correcções, agronómico) — acceptable for MZ formal writing; not Brazilian “você” marketing tone |
| “Produções” | Used for yields — clear in agri context |
| “Rendimento” | Household income — OK; avoid confusing with crop yield |
| “Unidades fantasma” | Good calque of ghost units |
| “Linha de base local” | Correct for baseline |
| Tone | Formal, respectful — fits community/first contact |

No major grammar blockers. Prefer **one** consistent spelling set (European PT is fine).
