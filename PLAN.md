# GroundYield — Public Plan

**Open modular high-productivity farm pilot**  
Vilanculos, Inhambane Province, Mozambique

This document is public by design. It will be updated as reality changes.

---

## The Problem

Smallholders in southern Mozambique (and much of sub-Saharan Africa) operate far below potential yields. The gap is not primarily knowledge or effort — it is access to reliable water, improved inputs, basic storage, and timely advice. Most interventions are opaque, slow, and non-replicable.

## The Approach

Deploy standardized, modular farm units that close the yield gap with measurable results. Every cost, yield, income figure, and failure is published in real time. The model is designed to be copied.

### Core Package (per modular unit)
- Solar-powered irrigation
- Improved / hybrid seeds + micro-dosing fertilizer
- Phone-based AI agronomy advice
- Hermetic storage (reduce post-harvest loss)
- Optional poultry and goat modules for income diversification

### Design Principles
1. **Modular** — start small, prove, then scale by adding units
2. **Transparent** — no private reports, no hidden numbers
3. **Replicable** — anyone should be able to copy the model
4. **Local first** — community land and farmers, not imported labor
5. **Measured** — baseline → intervention → public results

---

## Public Charter (Season 1)

- Deploy **30–60 modular units** in the Vilanculos area
- Target **80–100%+ yield increase** on staple crops vs local baseline
- Raise household income through cash crops + poultry modules
- Publish costs, yields, incomes, and failures in real time
- Produce an open, replicable model others can adopt

## Phases

### Phase 0 — Foundation (Current)
- Public identity locked (website, GitHub, X)
- Open plan published
- Ground trip: South Africa → Zimbabwe → Mozambique
- Land options, community engagement, baseline data collection

### Phase 1 — First Units
- Secure land access with community
- Deploy initial modular units (start small)
- Establish baseline yields and costs
- Begin public data logging

### Phase 2 — Season 1 Proof
- Scale to 30–60 units
- Full public reporting of yields, costs, incomes
- Iterate on package based on field results
- Document failures openly

### Phase 3 — Replication
- Open playbook released
- Others can copy the model with confidence
- Expand only after proof

---

## Location Rationale

**Vilanculos, Inhambane Province, Mozambique**
- Relatively stable southern coast
- Existing smallholder systems
- Tourism market creates demand for fresh produce
- Manageable scale for a transparent pilot

---

## What We Will Publish

- Unit design and bill of materials
- Input costs and supplier notes
- Baseline vs treated yields
- Household income changes
- Failures and course corrections
- Community agreements (as appropriate)

No private reports. The data is the product.
