# Contributing to GroundYield

Thank you for caring about open, measurable smallholder pilots.

## Ways to help

| Path | How |
|------|-----|
| **Report an error** | [Open an issue](https://github.com/groundyield/website/issues) — wrong number, broken link, unclear claim |
| **Improve docs** | Pull request against markdown in this repo (PLAN, UNIT, DATA, etc.) |
| **Field / local knowledge** | Email team@groundyield.org (Portuguese welcome) — markets, water, varieties near Vilanculos |
| **Suppliers / tech** | Email with location, product, and rough prices (we may publish ranges, not spam your inbox) |
| **Code / site** | PRs for static site quality (a11y, i18n, data tables). Keep the stack simple: no framework required |
| **Replication** | After Season 1 data exists, copy the model and publish *your* costs and yields |

## What we are not asking for (yet)

- Cold outreach that demands equity or exclusivity without reading the Charter  
- Household data collection by third parties without [CONSENT.md](CONSENT.md)  
- “AI partnership” pitches that hide model, cost, or data use  

## Pull request guidelines

1. Prefer small, reviewable PRs.  
2. Do not invent field numbers — label estimates as estimates.  
3. Link sources for yield, price, or policy claims.  
4. Match existing tone: plain, measurable, failure-tolerant, integrity-first ([INTEGRITY.md](INTEGRITY.md)).  
5. Never invent field numbers or “clean up” failures in a PR without a dated correction note.  
6. MIT license — contributions are under the same license.

## Conduct

Be respectful to farmers, partners, and reviewers. No harassment. Disagreement about methods is welcome; personal attacks are not.
