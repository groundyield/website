## North star (stable intent)

> Raise **real** smallholder yields near Vilanculos with a **modular, measured, open** package — and publish costs, yields, and failures so others can copy or reject with eyes open.

Not: rebuild a silent large-farm empire.  
Not: AI or Starlink as a substitute for land and water.

## Phase 1 — First modular units

**Intent:** Prove **one** (then few) units can exist honestly — not 60 on paper.

| Milestone | Proposed order | Done when | Depends on |
|-----------|----------------|-----------|------------|
| Written land/use legitimacy | Before capital | Annex / witness notes | Community G1 |
| Water source **F** | Before pump buy | Depth/distance measured | Site walk |
| Site theft plan | Before install | SECURITY_THEFT checklist | Trip |
| Named custodian + train | Before leave | Name + training done | VALUE_AND_MONEY annex |
| Unit capital spent | After § pre-unit checklist | RISK_AND_GAPS §5.2 | Quotes G2 |
| **G6** Registry row | Same week as install | units.html + CSV | Integrity |
| **G3** Baseline complete | Before any % claim | Baseline CSV method | DATA / KPI |
| Cost actuals vs quote | Within 30 days of install | Public note | SUPPLIERS |

**Design scale (aspirational, not promised):** start **1–3** units; grow only with registry rows.  
Charter “30–60” remains an **aim if earned** ([CHARTER.md](CHARTER.md)).

**Exit to Phase 2:** ≥1 active unit through a meaningful growing period with public costs + baseline (full harvest may complete in Phase 2).
