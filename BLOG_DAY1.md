# Day one, in public — what GroundYield is and is not

**27 July 2026**  
Jacques Theron · GroundYield  
https://www.groundyield.org

---

This project is **one day old** as a public stack: domain, GitHub identity, website, and a pile of open documents landed in the same window. That fact should sit at the top of any introduction — not in a footnote.

GroundYield is an attempt to run a **modular smallholder farm pilot** near Vilanculos, Inhambane Province, Mozambique, with costs, yields, and failures published openly. The operator is me, **Jacques Theron**. It is **self-funded**. There is **no legal entity yet**. There is **no local partner named on the accountability page**, because none has agreed in public.

If you only remember one thing: **nothing has been measured on a pilot plot.** Zero units installed. Zero local baselines recorded. Zero written supplier quotes in the log. Trip dates still open.

## What exists

- A public site and open repository: design notes, charter, integrity rules, Portuguese page, offline field pack (forms + one-pager).  
- A **public unit registry** that currently shows **0**: https://www.groundyield.org/units.html  
- Cost bands and economics tables labeled as **planning** material — placeholders where field prices should eventually sit.  
- Season 1 figures such as “on the order of 30–60 units” or large staple yield gains vs local baseline: **design aims / hypotheses**, not results. The charter was updated to say that explicitly after internal critique.

## What does not exist

- Land access secured for the pilot  
- Farmers enrolled  
- Agronomy rates to enrolled farmers (L2/L3) — **gated** until G5-A/B; L1 choice demos only ([AI_FIELD_PATH.md](AI_FIELD_PATH.md))  
- An independent auditor, board, or NGO co-signer verifying claims  
- A disclosed multi-month runway number (the stop scenario is described; the dollar figure is still a gap)

## Why publish before the trip

Most projects write the measurement rules after the first good photo. We are trying the opposite: write **anti-fraud and data rules first**, so the temptation to invent wins has something public to collide with.

That includes:

- Baseline before impact claims  
- Truth marks (fact / estimate / hearsay) in the field  
- No silent rewrites — dated corrections  
- Dual evidence before headline yield claims  
- Unit counts only from a registry, not vibes  

Full text: [INTEGRITY.md](INTEGRITY.md).

Paper is cheap. Field reality is not. Publishing early only works if we **keep the stage honest** when people arrive.

## The adversarial review (and what it got right)

On day one, an adversarial review of this stack said roughly:

1. **Velocity vs reality** — institutional-looking docs far ahead of any ground contact.  
2. **Self-referential trust** — named founder without external co-signer is still weak accountability.  
3. **Targets before feasibility** — quantitative aims published before baselines.  
4. **Process miss** — some “shipped” claims briefly outran live HTTP 200s during messy deploys.  
5. **Legal/agronomy exposure** — draft farmer advice must not go live without review.  
6. **Money stop risk** — households must not be enrolled into silent abandonment.

Those points were **substantially right**. Deploy is healthy now (production equals `main`; live-verify passes). The strategy risk remains: **more markdown does not create a pilot.**

We responded by:

- Append-only correction for early “shipped” failures  
- Softening charter language (binding process vs aspirational targets)  
- Freezing agronomy send  
- Naming runway/stop and external-accountability gaps on WHO  
- Putting “zero units / zero baselines” on the homepage  

That is not virtue. It is the minimum if “no BS” is a real claim.
